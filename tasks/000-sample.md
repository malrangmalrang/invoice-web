# Task 000: 샘플 작업 파일

## 개요

이 파일은 새로운 작업 파일을 생성할 때 참고할 수 있는 샘플 템플릿입니다.

## 명세서

- 작업의 목적과 배경을 설명합니다
- 구현해야 할 기능의 상세 요구사항을 기술합니다
- 관련 PRD 기능 ID를 참조합니다 (예: F001, F002)

## 관련 파일

- `app/example/page.tsx` - 메인 페이지 파일
- `lib/example.ts` - 유틸리티 함수
- `types/index.ts` - 타입 정의

## 수락 기준

- [ ] 기능이 정상적으로 동작한다
- [ ] TypeScript 타입 에러가 없다
- [ ] 반응형 디자인이 적용되었다
- [ ] 에러 처리가 구현되었다

## 구현 단계

### 단계 1: 기본 구조 생성

- [ ] 파일 생성 및 기본 구조 작성
- [ ] 필요한 패키지 설치

### 단계 2: 핵심 기능 구현

- [ ] 메인 로직 구현
- [ ] 타입 정의 추가

### 단계 3: UI 연동
